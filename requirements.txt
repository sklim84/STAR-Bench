# STAR-Bench dependencies (Python 3.12).
#
# There are two environments, and they are not installed together. A single file
# could not hold both: the serving stack follows vLLM's and torch's numpy and the
# tool layer needs numpy 2 for DuckDB, PyArrow and XGBoost, so one pin here would
# satisfy neither and the run would not install on another machine.
#
#   serving host:      _experiments/env/requirements-serving.txt
#   evaluation host:   _experiments/env/requirements-eval.txt
#                      plus ../STAR-Bench-Web/requirements-tools.txt
#
# Verify an installed environment with:
#
#   python -m _experiments.env.check_env            # evaluation stack
#   python -m _experiments.env.check_env --serving  # serving stack
#
# Container recipes for both are in _experiments/env/. Model snapshot revisions
# are pinned in _experiments/scripts/model_revisions.json and the serving
# configurations in _experiments/scripts/runner/registry.py; every run record
# carries the commit, the data hashes and the versions it ran with.
