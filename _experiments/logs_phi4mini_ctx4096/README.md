# Phi-4-mini 멀티턴 실패 실행 (컨텍스트 4096)

vLLM 이 `microsoft/Phi-4-mini-instruct` 를 `max_model_len 4096` 으로 띄웠다.
도구 23종 스키마와 시스템 프롬프트만으로 4,097토큰이라 **첫 요청부터 컨텍스트를 넘겨
219턴 전부 400 Bad Request 로 거부**됐다. 도구 호출이 하나도 기록되지 않아
`h̄ = .0633` 이 나왔는데, 이는 성능이 아니라 전량 실패다.

`run_benchmark.sh` 의 `phi-4-mini` 항목에 `--max-model-len` 이 없어 vLLM 이 모델 설정을
따랐다. Phi-4-mini 는 실제로 128K 컨텍스트를 지원하므로 명시했어야 한다.

단일턴은 프롬프트가 짧아 4,096 안에 들어가 `h = .6423` 으로 정상이었다.

재실행(`--max-model-len 12288`) 결과는 상위 디렉터리에 있다.

| | 이 디렉터리 | 재실행 |
|---|---|---|
| 400 오류 | 438건 | 11 / 21건 |
| no-call | 219/219 (100%) | 44/219, 79/219 |
| oracle h̄ | .0633 | **.6313** |
| real h̄ | .0633 | **.4697** |

어떤 분석에도 사용하지 말 것.
